# 本地配置后台与安装器计划

## 目标

降低 FCGO 的安装和维护门槛。用户安装后应优先通过本地配置网页完成配置，而不是直接编辑源码或大量环境变量。

## 当前实现

- 新增本地配置后台入口：`/admin`。
- 新增首次运行配置向导入口：`/admin/setup`。
- 新增机器人菜单事件：`fcgo.admin.open`。
- 新增文本入口：`/配置`、`/后台`。
- 后台使用飞书 OAuth 登录；首次登录的飞书用户绑定为本机后台管理员。
- 当前后台支持编辑个人助手名称/简介、长期记忆开关、长期记忆内容、个人默认模型。
- 当前后台采用普通配置 + 独立高级配置页：普通配置展示常用开关、模式和 Provider；`/admin/advanced` 保留完整参数编辑能力。
- 当前后台支持编辑 `Settings` 中声明的环境参数，并写入 `FCGO_ADMIN_CONFIG_PATH` 指向的配置文件；默认写入项目 `.env`。
- 当前后台列出机器人自定义菜单的全部已支持事件 key，方便在飞书开发者后台逐项配置。
- 模型密钥、飞书 App ID、机器人 Open ID 和本地配置路径只展示是否已配置，不在页面回显明文；输入框留空表示不修改，点击“清空”按钮并保存才会删除。
- Provider 和模型名在普通配置中保持联动；不允许保存明显不匹配的个人默认模型或系统默认模型。
- 已配置模型接口会显示连接测试按钮，用当前运行配置发起一次短模型请求，验证 API Key、Base URL 和模型名是否可用；测试结果就近显示在对应接口卡片内。
- 已配置媒体与工作流接口会显示连接测试按钮，后台会对接口地址做一次轻量 HTTP 连通性检查；结果就近显示在对应卡片内。
- 普通配置页支持“保存所有配置 / 重置所有配置”，每个主要卡片也支持“保存 / 重置”。重置只恢复页面加载时的值，不会写入配置文件。
- 普通配置页和高级配置页共用同一套控制台式视觉规范；敏感字段使用输入框加独立“清空”按钮的布局，避免按钮贴近字段说明或造成误触。
- 首次配置向导按服务地址、飞书应用、模型接口、常用能力、飞书菜单和最终检查分步展示；向导只保存首次配置相关字段，不会修改助手个人偏好和长期记忆。
- 模型和媒体测试按钮使用前端异步请求，不刷新页面、不改变滚动位置；测试结果 5 秒后自动消失。
- 全局环境参数保存后需要重启服务才会完全生效。

## 管理员模型

- 本地配置后台是单机管理入口，不是多租户云后台。
- 首次成功登录 `/admin` 的飞书用户会绑定为管理员。
- 后续只有该飞书用户可以访问和修改后台配置。
- 管理员绑定保存在 SQLite 的 `app_settings.admin_owner_open_id`。
- 更换管理员需要在本机数据库中显式清除绑定，避免链接分享导致接管。

## 当前配置范围

后台会根据 `fcgo.config.Settings` 自动生成配置表单。当前已覆盖：

1. 飞书应用配置：App ID、App Secret、Verification Token、Encrypt Key、Base URL、OAuth 回调地址相关参数。
2. 模型接口配置：Gemini、DeepSeek、OpenAI、Qwen、Doubao、Minimax、Claude 的 Key、Base URL、Model。
3. Agent 配置：`FCGO_AGENT_MODE`、最大工具步数、工具超时。
4. 写入配置：写入开关、默认确认策略、是否允许用户开启低风险自动执行。
5. 附件能力：图片理解、音视频理解、OCR、附件大小限制。
6. Web 读取：允许域名、禁止域名、超时和大小限制。
7. 用户偏好：助手名称、简介、个人默认模型、记忆开关。

敏感字段采用“只写不读”策略：页面可覆盖密钥，但不会显示现有密钥明文。

普通配置页只展示：

- 助手名称、简介、当前用户长期记忆开关和可编辑记忆内容。
- 运行模式、服务地址、Agent 模式。
- 飞书应用必要字段。
- 个人默认模型、系统默认模型、已配置模型接口、接口显示名称，以及“添加模型接口”入口。
- 已配置模型接口卡片支持编辑、测试连接、设为系统默认和删除；当前系统默认模型接口不可删除，需要先切换默认。
- 资源搜索、图片理解、音视频理解、OCR、网页读取、写入开关和写入策略。
- 媒体与工作流接口的已配置状态、显示名称，以及“添加媒体/工作流接口”入口。
- 已配置媒体与工作流接口卡片支持编辑、测试连接和删除。
- 普通页和高级页都从同一个配置文件快照渲染，避免同一个参数在两个页面显示不一致。

首次配置向导页 `/admin/setup` 展示：

- 未绑定后台管理员时，允许本机访问 `http://127.0.0.1:8000/admin/setup`
  完成首次配置，不要求用户先通过飞书登录。
- 完成飞书应用配置后，用户再通过飞书登录绑定后台管理员；绑定后后台只允许该飞书用户访问。
- 配置进度：服务地址、飞书应用、模型接口、默认模型。
- 服务地址、机器人授权回调地址和后台登录回调地址。
- 飞书应用必要字段。
- 系统默认模型、已配置模型接口、模型接口测试和添加模型弹窗。
- 常用能力开关。
- 推荐添加的飞书菜单 key。
- 保存后重启服务、测试模型、验证机器人菜单和飞书消息的检查清单。

首次配置完成并绑定管理员后，普通后台不再显示首次配置向导入口。管理员需要重新跑向导时可以手动访问 `/admin/setup`。

高级配置页 `/admin/advanced` 保留：

- SQLite、长连接、代理、scope、超时、最大字节数、最大字符数、上下文窗口、缓存、回滚和限流等细节参数。
- 助手默认名称/简介等开发者级默认值。
- 后台会话密钥和配置文件位置。

后台页面不允许直接关闭 `FCGO_ADMIN_ENABLED`，避免管理员从网页把后台锁死。

当前模型和媒体接口仍遵循运行时架构限制：每个内置 Provider 保存一套 API Key/Base URL 配置，同一 Provider 下可以选择不同模型或接口显示名称；同一 Provider 多套 API Key/Base URL 连接、按别名路由调用需要后续 profile 架构支持。

## 安装器路线

1. 桌面启动器
   - 启动/停止/重启本地服务。
   - 重启逻辑复用 `scripts/restart_server.py`，返回明确 JSON 和健康检查结果。
   - 自动打开 `/admin`。
   - 健康检查失败时展示明确错误。

2. 首次运行向导
   - 引导填写飞书应用信息和模型 Key。
   - 生成 OAuth 回调地址、事件订阅说明和菜单 key 清单。
   - 执行本地 doctor 检查。

3. 跨平台打包
   - Windows 优先输出可双击启动的安装包或单文件启动器。
   - macOS/Linux 在 Windows 版本稳定后补齐。
   - 打包产物默认使用用户目录下的配置文件和 SQLite 数据库。

## 飞书侧仍需用户操作

飞书开放平台当前仍需要用户手工创建或确认自建应用、权限、事件订阅和菜单。程序可以生成清单并检查配置，但不应默认代替用户修改飞书开发者后台。

## 验收

- 从飞书菜单点击“本地配置网页”可以打开 `/admin`。
- 未登录时只能看到飞书登录入口。
- 首次登录用户自动绑定为管理员。
- 非管理员访问后台被拒绝。
- 保存助手名称和简介后，飞书私聊回复、帮助和菜单文案使用新名称。
- 模型密钥不在页面明文展示。
