# 助手命名与用户偏好记忆规格

## 目标

飞灵（FLGO） 支持用户把助手调整成更符合自己工作习惯的形态，但个性化能力必须可解释、可管理、可撤销。助手名称和偏好记忆只影响当前用户或明确作用域内的体验，不改变飞书机器人真实应用名称，不保存完整聊天原文，也不建立用户不可见的画像。

本规格约束后续 `UXS-43` 到 `UXS-47` 的实现。隐私、安全和审计边界必须同时遵守 [上下文读取、用户授权和长期记忆隐私规格](context-privacy-memory.md)。

## 助手名称

### 作用域

- 全局默认名称：部署默认值，未设置个人名称时使用，当前默认是 `飞灵`，可通过 `FLGO_ASSISTANT_DEFAULT_NAME` 调整。
- 用户个人名称：私聊中优先使用，只对设置该名称的用户生效。
- 会话或群聊名称：后续增强项。MVP 不实现群聊级名称，避免一个成员的偏好影响整个群。

名称设置不影响：

- 飞书开放平台里的 Bot 名称。
- 其他用户看到的助手名称。
- 已写入历史消息中的旧文本。

### 用户操作

MVP 指令：

```text
/助手 名称
/助手 命名 飞灵
/助手 默认名称
```

预期行为：

- `/助手 名称`：返回当前用户使用的助手名称，以及是否来自个人设置或全局默认。
- `/助手 命名 飞灵`：设置当前用户的个人助手名称。
- `/助手 默认名称`：删除当前用户的个人名称，恢复全局默认。

名称校验：

- 去除首尾空白。
- 禁止换行、控制字符和明显会破坏飞书 Markdown/卡片展示的字符组合。
- 建议长度限制为 1 到 20 个可见字符。
- 空名称、过长名称或非法字符必须返回明确提示，不写入数据库。

### 展示位置

MVP 必须覆盖：

- 私聊普通回复中的助手自称和简短确认文案。
- `/帮助`、`/授权`、`/模型`、`/记忆`、`/上下文 查看` 等命令回复。
- 飞书自定义菜单触发后的回复文案。
- 模型系统提示词中的“当前助手名称/自称”。

MVP 不要求覆盖：

- 飞书应用后台 Bot 名称。
- 群聊级自定义名称。
- 历史消息回填。

## 用户偏好记忆

### 记忆类型

MVP 支持保存结构化摘要或键值偏好，不保存完整聊天原文。推荐类型：

- `称呼`：用户希望助手如何称呼自己。
- `语言风格`：例如简洁中文、正式、直接、少解释。
- `输出格式`：例如优先表格、先结论后步骤、代码块格式。
- `常用项目`：例如项目代号、常处理业务线、常用文档范围。
- `工作习惯`：例如先给人工测试步骤、每组任务完成后同步 Linear。
- `会话摘要`：超过近期窗口的私聊上下文摘要，用户可查看和删除。

禁止保存：

- 完整聊天流水。
- 完整飞书文档、网页、附件正文。
- OAuth token、API key、手机号、身份证号、银行卡号等敏感凭证或高风险个人信息。
- 群聊里未经过用户私聊确认的个人偏好。

### 用户操作

MVP 指令：

```text
/记忆 查看
/记忆 记住 输出尽量用表格
/记忆 修改 语言风格=简洁中文
/记忆 删除 语言风格
/记忆 清空
/记忆 关闭
/记忆 开启
```

当前已实现的 `/记忆 查看`、`/记忆 删除`、`/记忆 关闭`、`/记忆 开启` 行为保持兼容：

- 关闭记忆只暂停新增记忆和暂停注入模型上下文，不清空已有记忆。
- 删除或清空记忆必须可由用户主动触发；批量删除需要二次确认卡片。
- 查看记忆只能返回当前用户自己的摘要或偏好，不展示完整聊天原文。

后续新增的 `记住`、`修改`、按键删除必须写入审计日志，并记录来源为用户手动操作。

### 模型建议与确认

模型可以识别候选偏好，但不能静默写入长期记忆。

流程：

1. 模型从当前私聊对话中识别候选偏好。
2. 系统把候选内容以确认卡片或明确文本展示给用户。
3. 用户确认后写入长期记忆；用户取消或无响应则不写入。
4. 群聊中识别到个人偏好时，只能提示用户到私聊确认。

候选内容必须经过长度限制和敏感信息过滤。模型建议本身不应写入长期记忆，除非用户确认。

## 存储与审计

助手名称建议存储为用户级偏好记录，至少包含：

- `user_open_id`
- `assistant_name`
- `updated_at`
- `source`

偏好记忆建议继续使用长期记忆表，至少区分：

- 记忆类型或 key。
- 摘要内容或 value。
- 来源：用户手动、用户确认模型建议、会话摘要。
- 更新时间。
- 是否启用。

审计日志需要记录：

- 助手名称查看、设置、恢复默认。
- 记忆新增、修改、删除、清空、开启、关闭。
- 模型建议记忆的确认或拒绝。

审计日志不得记录完整聊天正文、完整资源正文或 token。

## 模型上下文

构造模型请求时：

- 注入当前助手名称，让模型以该名称自称。
- 只注入当前用户启用状态下的偏好记忆摘要。
- 优先注入高价值、短文本、近期更新的偏好。
- 受 `FLGO_MEMORY_CONTEXT_MAX_CHARS` 限制。
- 群聊默认不注入任何成员的个人偏好记忆。

如果用户关闭长期记忆，模型上下文不得包含该用户的长期记忆，但助手名称仍可继续生效，因为它是显示偏好，不属于长期记忆内容调用。

## MVP 范围

进入 MVP：

- 用户级助手名称：查看、设置、恢复默认。
- 私聊回复、帮助/菜单/命令文案、模型提示词使用用户级助手名称。
- 用户偏好记忆 CRUD：查看、新增、修改、删除、清空、开启、关闭。
- 关闭记忆只暂停，不清空。
- 删除/清空二次确认。
- 模型建议记忆必须用户确认后写入。
- 中文用户操作文档和测试覆盖。

后续增强：

- 群聊或话题级助手名称。
- 偏好分类编辑 UI。
- 记忆重要性排序、过期时间和归档。
- 跨设备导入/导出偏好。
- 向量检索或长期资料索引；引入前必须先设计删除策略和隐私边界。

## 验收标准

- 用户能明确知道当前助手名称和长期记忆的来源、作用域和删除方式。
- 私聊中一个用户的名称和偏好不会影响其他用户。
- 关闭记忆后，模型不会再收到该用户的长期记忆。
- 查看记忆不会展示完整聊天原文。
- 规格与 `context-privacy-memory.md` 的隐私边界一致。
