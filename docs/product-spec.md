# FCGO MVP 产品规格

## 产品定位

FCGO 是一个使用 Python 3.13 和 uv 本地部署的飞书 AI 工作助手。用户通过飞书私聊或群聊 `@机器人` 使用自然语言提问，系统按用户授权读取飞书资料和当前会话上下文，调用已配置的模型生成回答并回复到飞书。

当前产品支持读取能力和确认式写回。写回由 `FCGO_WRITEBACK_ENABLED` 控制；
开启后仍必须先生成确认卡片，用户确认后才执行，默认不会静默写入。

## 核心用户闭环

### 普通对话

1. 飞书长连接收到私聊消息或群聊中的 `@机器人` 消息。
2. FCGO 读取当前会话有限范围内的近期上下文。
3. `ModelRouter` 根据部署默认值、会话设置或用户偏好选择可用模型。
4. 模型生成简洁回答。
5. FCGO 将回答发送回原飞书会话。

### 飞书资料搜索和读取

1. 用户用自然语言要求查找飞书文档、电子表格、多维表格、Wiki 或文件，或直接发送资源链接。
2. Agent 根据用户意图生成搜索查询并调用飞书搜索/读取工具。
3. 搜索和读取使用当前用户 OAuth，仅访问用户本人有权读取且应用 scope 允许的资源。
4. Agent 依据真实搜索结果和读取内容回答，不得编造标题、链接、token 或正文。
5. 搜索结果优先使用飞书真实返回的可打开 URL；缺少 URL 时才使用配置的租户文档域名拼接。

### 上下文和长期记忆

1. 当前会话上下文默认开启，近期消息在条数、时间和字符预算内按需进入模型。
2. 超出近期窗口的旧消息可压缩为会话摘要，不长期保存完整聊天原文。
3. 私聊用户可以查看、开启、关闭、修改和删除自己的长期记忆。
4. 普通聊天中识别到称呼、项目代号或输出偏好等候选记忆时，必须由用户通过确认卡片同意后写入。
5. 群聊不展示或写入成员的个人长期记忆。

## 当前能力范围

- 本地单实例运行，不提供多租户 SaaS。
- 飞书长连接消息入口、私聊回复和群聊 `@机器人` 回复。
- 飞书 OAuth 授权、token 持久化和可选 refresh token 自动续期。
- 飞书文档、Wiki、电子表格、多维表格和普通网页按需读取。
- 基于模型的资源搜索意图识别、关键词规划、多查询搜索和真实结果汇总。
- 当前会话近期上下文、滚动摘要和短期 TTL 缓存。
- 用户可管理的助手名称和长期记忆。
- Gemini、OpenAI-compatible 和 Anthropic Claude 文本模型 Provider。
- Provider 级超时、并发限制、错误脱敏和模型调用元数据审计。
- SQLite 本地保存授权、偏好、记忆、幂等键和审计事件。

## 安全与隐私默认值

- 真实密钥只通过环境变量或 `.env` 注入，不得提交到仓库。
- API key、OAuth token、Authorization header 和常见密钥格式在日志与错误中脱敏。
- 默认不持久化飞书资源正文、网页正文、附件正文或完整聊天原文。
- 搜索和读取必须同时满足用户资源权限和飞书应用 API scope。
- 审计日志只记录事件、provider、model、latency、usage、结果数量和错误类型等元数据。
- 超长消息、资源内容、上下文和长期记忆均受代码级字符或数量预算约束。
- test 环境默认限制模型输出 token；dev/prod 可显式设置成本上限。
- 写回能力默认关闭，避免未经确认修改用户飞书资料。

## 写回边界

当前基线不执行以下操作：

- 创建、修改、追加或删除飞书文档内容。
- 写入电子表格单元格。
- 创建、更新或删除多维表格记录。
- 代替用户发送群消息或私聊消息。

用户提出这类请求时，助手可以返回可复制草稿、摘要或人工操作建议。是否恢复写回、启用确认后写回或低风险自动写回，由独立写回任务重新评估，不属于本规格的读取基线。

## 非目标

- 不替换飞书官方 Aily 或飞书原生 AI 产品。
- 不建设全量云空间索引、企业知识库或长期 RAG 数据库。
- 不全量扫描用户飞书云空间。
- 不提供可视化工作流编排平台。
- 不在当前基线执行媒体生成或外部工作流 Provider。
- 不自动执行定时任务或后台推送。

## 验收标准

### 服务和配置

- `uv sync` 可以安装依赖。
- `uv run fcgo serve` 可以启动服务。
- `GET /healthz` 返回 `{"status": "ok"}`。
- `uv run fcgo doctor` 可以检查飞书和默认模型配置。

### 飞书消息

- 私聊文字消息可以进入 Agent 并回复原会话。
- 群聊只有在 `@机器人` 时进入 Agent。
- 重复消息事件不会产生重复回复。
- 超长消息在调用模型前被拒绝并给出可操作提示。

### 模型

- 至少配置一个真实 Provider 后可以生成回答。
- 用户可以通过飞书自定义菜单切换已配置模型。
- Provider 失败时返回脱敏且可理解的错误。
- 模型调用审计不包含用户正文或完整 prompt。

### 资源读取

- 用户可以直接发送飞书文档、电子表格、多维表格或网页链接并获得基于真实内容的回答。
- 用户可以用自然语言搜索本人可读的飞书资料。
- 无结果时明确说明未找到，不生成虚假标题或链接。
- 缺少用户授权、应用 scope 或资源权限时，错误原因必须区分清楚。

### 上下文和记忆

- 当前会话近期消息可以用于回答“刚才聊了什么”等问题。
- 超过预算的历史消息不会无限注入模型。
- 用户可以查看、关闭、开启、修改和删除自己的长期记忆。
- 候选偏好只有在用户确认后写入；关闭记忆不会清空已有内容。

### 质量

- 自动测试不依赖真实飞书或模型额度。
- `uv run pytest -q`、`uv run ruff check .` 和 `uv run mypy` 通过。
- 飞书文档和知识库页面中的 PDF 附件可读取默认前 2 页或用户指定页。
- DOCX、XLSX、PPTX、文本、结构化文本和常见源码附件可提取正文。
- 图片返回格式、尺寸和文档描述；扫描图片明确提示未执行 OCR。
- 音视频、压缩包、旧版 Office 和可执行文件只返回元数据与安全限制。
- 文档中的普通超链接、`@文档` 和内嵌网页返回飞书实际提供的标题、显示文本与 URL。
- 单个附件损坏或不支持时，不影响外层文档正文和其他内嵌对象的读取。

### 写回历史与撤回

- 所有成功写回记录 action、actor、类型、目标、结果和可撤回元数据。
- 多维表新增记录保存新 `record_id`，撤回时生成删除记录确认卡片。
- 电子表格范围写入前读取并保存同范围旧值，撤回时生成恢复旧值确认卡片。
- `/查看最近写回` 展示最近执行记录和可撤回状态；`/撤回` 只选择最近一次安全可撤回记录。
- 文档创建/追加、消息发送等无法可靠证明回滚边界的操作明确标记为不可撤回。
- 撤回成功写入独立审计事件；重复确认和重复撤回不会再次执行。
