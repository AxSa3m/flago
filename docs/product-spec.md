# FCGO MVP 产品规格

## 目标

FCGO 的 MVP 目标是提供一个 Gemini 驱动的飞书工作助手，让用户在飞书中通过机器人处理工作内容。第一阶段先完成真实最小闭环：用户在飞书发送消息，FCGO 调用 Gemini，并把结果回复回飞书。

## 用户场景

- 用户私聊机器人，询问通用问题或要求生成工作文本。
- 用户在群聊中 @机器人，让它基于当前输入生成回复。
- 用户发送飞书文档、电子表格、多维表格或网页链接，让机器人读取并总结/分析。
- 当前分支暂停写回能力；用户要求写入时，机器人只返回草稿或操作建议。

## MVP 范围

- 支持本地运行，不做多租户 SaaS。
- 支持 Gemini API Key，不接 Vertex AI。
- 支持飞书长连接消息入口。
- 支持用户 OAuth，为访问用户私有飞书资源预留权限链路。
- 默认不持久化飞书正文，只保存运行状态。

## 非目标

- 不替换飞书官方 Aily 的底层模型。
- 不做可视化工作流编排平台。
- 暂不执行写入、修改、删除或创建飞书资源。
- 不在 MVP 中建设长期知识库或 RAG 索引。

## 验收标准

- 本地服务可通过 `uv run fcgo serve` 启动。
- `/healthz` 返回健康状态。
- 飞书消息可被路由为统一助手请求。
- Gemini Provider 可通过 `GEMINI_API_KEY` 真实调用。
- 飞书文档、电子表格、多维表格和网页链接可以按需读取并用于回答。
